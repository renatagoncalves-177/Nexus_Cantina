# Orientações para uso de IA neste repositório

Sempre que uma IA criar, excluir ou modificar um arquivo deste projeto, ela
deve atualizar também o arquivo `documentacao-ia/REGISTRO_IA.md`.

O registro deve:

- usar linguagem simples e natural;
- informar a data da alteração;
- citar o caminho de cada arquivo criado, excluído ou modificado;
- explicar resumidamente o que a IA fez;
- não incluir senhas, tokens ou outros dados confidenciais;
- diferenciar, quando necessário, o trabalho da IA das alterações feitas pela
  equipe.

Alterações apenas de consulta, testes que não mudam arquivos e comandos Git não
precisam ser registrados.
